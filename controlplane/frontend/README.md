# PressureCooker 前端

Vue 3 + Vite 管理界面，覆盖项目、任务与历史、结构化报告、流程编排、接口管理、项目环境、CSV 数据集、集群、MCP 工具目录和使用指引。Scalar 提供接口编辑，LogicFlow 提供流程画布；自研服务位于相邻 Go 模块。

用户入口见[平台说明](../../README.md)、[部署与使用](../../docs/部署与使用.md)、[流程画布与接口管理](../../docs/流程画布与接口管理.md)和[项目与接口复用](../../docs/项目与接口复用.md)。报告口径以[报告契约](../../PRESSURE-REPORTS.md)为准。

## 开发、测试与构建

需要 Node 22.12.0 或更高版本，依赖锁定在 `package-lock.json`。在本目录执行：

```bash
npm ci
npm run dev
```

本地开发服务将相对 `/api` 请求转发到 `http://127.0.0.1:18090`，管理端需单独准备。生产构建生成 `dist/`，由 Go 管理端在 `/` 提供；浏览器使用平台会话 Cookie，写操作携带 CSRF 校验。

```bash
npm test
npm run build
```

定向测试可传入文件，例如：

```bash
npm test -- src/datasets/DatasetManagement.test.js
npm test -- --maxWorkers=1 src/reports/Reports.test.js
```

测试包含 Vue/jsdom 交互、项目作用域及偏好恢复、接口/流程、数据集、报告和离线导出契约。使用真实组件验证请求及页面行为，外部请求使用受控夹具；不要求启动真实业务压测。同一工作区应避免并行重复运行完整测试。

项目级 Go、MCP 契约、隔离数据库与前端统一验收见[测试基线与验收](../../docs/测试基线与验收.md)。构建及官方运行时准备见[部署与使用](../../docs/部署与使用.md)。前端构建成功只说明当前源码可生成产物，不代表远端已部署或通过现场验收。

## 代码与状态边界

| 目录或组件 | 职责 |
| --- | --- |
| `App.vue`、`Login.vue`、`Workspace.vue` | 登录、项目切换、主导航、页面按需加载及离页修改处理 |
| `Runs.vue`、`CreateRun.vue`、`RunDetail.vue` | 任务筛选、提交、停止、执行快照、日志及原始文件 |
| `script-library/`、`workflow/`、`Plans.vue` | 脚本/流程统一工作区、结构树、画布、JMX 源码、版本和编译预览 |
| `api-management/` | 集合导入导出、HTTP/WS 调试、请求快照、协议描述和项目消息展示插件 |
| `projects/` | 项目管理、项目环境及各项目的页面/环境选择记忆 |
| `datasets/` | 文件目录、来源节点、CSV 上传、生成、分页预览和版本化编辑 |
| `reports/` | 报告版本、验收、节点详情、性能分析、监控证据、趋势及原件来源 |
| `Cluster.vue`、`McpTools.vue`、`guide/` | 集群状态、实时 MCP 参数参考及使用指引 |
| `api.js`、`hooks.js`、`ui/` | 项目作用域请求、会话/CSRF、取消旧请求、轮询与通用组件 |

项目切换先检查未保存修改和进行中的操作，再重建项目作用域。请求控制器捕获创建时的项目，迟到响应不写入新项目页面。每个项目独立恢复上次页面、报告选择和项目环境；没有记录时使用默认入口。流程和接口编辑器在同项目主导航切换时保留实例，项目切换不能携带旧项目草稿进入新项目。

浏览器偏好保存外观及受校验的项目、页面、环境和资源标识。密钥、环境值、消息正文和测试响应不作为浏览器导航偏好保存。项目资源由服务端持久化，保存遵循 revision 冲突检查；发布脚本和已提交任务保持不可变快照。

## 接口、环境与插件

项目环境提供固定 `base_host` 与普通自定义变量，集合只按稳定环境 ID 保存自定义覆盖；同名覆盖优先，空字符串也是明确值。调试和编排中的环境用于当前预览，任务创建时另行明确选择执行环境。

HTTP 支持浏览器直连和认证后的 master 转发。WebSocket 提供标准连接、传统 Socket.IO 握手与 `2::` 传输心跳、消息模板、手动发送、定时消息，以及默认空列表的通用 JSON 路径提取。数组结果可显式选择，运行时提取值只在当前连接中使用。

消息展示插件由项目创建、导入、安装并显式选择，新项目目录为空。配置型插件映射字段，JavaScript 插件在隔离运行时解析已有文本帧；展示不持有连接或发送入口。未知旧规则保留原配置并停止执行，不影响集合保存和连接；不可用插件引用回退原文。协议及插件边界见[接口插件说明](../../docs/interface-plugins.md)。

RPC、gRPC、Protobuf 和二进制编码目前为描述预留项，可保存和原样导出，不作为已有执行能力或 HTTP 请求执行。流程引用接口的精确修订，刷新引用需要明确操作，不能随集合更新自动改变已保存快照。

## 报告与原始文件

报告读取服务端保存的统计、版本和监控证据，支持验收目标、重新解析、节点及步骤筛选、趋势、对比和离线 HTML。浏览器不通过绘图重算报告结论。相邻有效观测点连线表示趋势，未采样时段不补造观测；明确缺失值处断开，悬停或键盘交互查看真实数值。

原始文件保留大小、SHA256、对象键、缺失及归档状态，并通过认证接口下载。历史校验信息和当前对象是否可用分别展示。冻结数据集的列、运行变量和文件回执来自任务快照，不随当前环境或数据文件编辑改变。

## MCP 与历史参考

MCP 页面从认证后的 `/api/mcp/tools` 获取实时目录，展示中文分类、参数、限制与返回参考，不在页面执行工具或显示凭据。工具数量和 schema 以实时目录为准，测试夹具不替代服务契约。只有有意更新 MCP schema 时才按[MCP 模块说明](../mcp-go/README.md)重新生成夹具并执行对照校验。

主题及通用下拉样式由 `theme.js`、`ui/` 和共享样式维护；原生选择器保留浏览器回退，自定义项目选择器保留键盘操作。[设计系统](design/design-system.md)和[视觉验收记录](design/visual-qa.md)保留历史设计背景，不能作为当前功能、部署状态或验收结果的替代证据。
