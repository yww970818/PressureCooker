# 统一脚本工作区设计约定

四张生成参考：library-preview.png、library-editor.png、api-management.png、dark-source-theme.png。

以用户最新要求为准：五项全局导航；脚本库与画布是同一个工作区，统一列表、同一详情，结构/流程/源码/版本四视图。概念中的已发布/草稿分区与“返回预览”独立编辑页不实现。编辑状态原位开启，列表可以折叠以增加画布空间。

年轻、轻快：白表面、近白淡紫背景，紫蓝主色与浅紫选中，小面积mint/peach组件类型。主体25px/14px，工具栏13px，代码等宽，约1.7px线条图标；10–12px面板、8px按钮、细边框、轻阴影。无统计装饰卡、无营销首屏。

色彩由src/styles.css共享tokens管理；theme.js只管理模式/主色偏好。浅/深/系统、紫蓝/薄荷/天空蓝；data-theme/data-accent为唯一全局状态。默认浅色紫蓝。深色图仅作为配色和代码区参考，保留浅色版的结构与项目品牌/现有功能，不增加图中搜索、铃铛、其他导航。

静态预览由真实数据驱动；生成图中的示例名称/日期/耗时只用于设计参考，运行页面不置入假业务数据。未知JMeter插件保留opaque XML。Scalar/LogicFlow实际组件与原生语义保持。
