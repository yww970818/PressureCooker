# 平台通用能力边界

PressureCooker 独立于被测项目。平台负责项目隔离、环境和集合、协议传输、数据集、流程发布、任务调度、原件归档及报告；业务的身份、命令、状态码和会话规则由项目维护。

长连接核心只处理 WebSocket 连接与原始帧、传统 Socket.IO 握手及传输心跳、显式配置的定时消息、模板和 JSON 路径提取。不会根据应用消息中的字段判断登录、主动结束业务会话、发送业务回执或注入业务变量。项目业务名称均为普通环境或运行变量，不享有隐式语义。

消息定制通过项目安装的配置型或 JavaScript 代码型插件解析与展示。默认目录没有业务插件。插件只读取已有帧并输出清洗后的消息结构，不能建立连接、发送消息、修改环境或读取凭据；发送仍由原调试面板处理。插件定义和安装状态按项目隔离，切换原文保留原始消息。当前插件契约与限制见[接口插件说明](interface-plugins.md)。

响应提取默认没有规则。用户显式新增完整 JSON 报文的路径和输出变量，多候选由用户选择。提取值属于当前连接，断开、重连或修改规则即清理。不支持的历史规则可查看及删除，但不执行，不阻止集合保存和切换。历史版本及任务快照不做隐式重写。

业务脚本、业务协议模拟器、专用生成器及历史测试资料归被测项目所有，不参与平台默认构建或验收。平台测试使用本机通用夹具、合成流程和内部目标，不依赖某个业务环境。历史业务资产已归档到相邻业务工作区，保留原字节和 SHA256；当前平台保留通用 CSV 示例。

已有实例的部署目录、Compose 名称、对象键、密文命名空间与历史发布指纹属于兼容契约，不能通过批量替换名称迁移。新安装使用通用默认值；旧实例显式保留其部署配置。详细操作见[部署与使用](部署与使用.md)。
