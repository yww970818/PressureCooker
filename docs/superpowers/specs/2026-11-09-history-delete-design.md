# 任务与报告删除

在任务与历史、压测报告列表提供单条删除、当前页勾选批量删除和当前项目一键清空。所有写入沿用现有认证、CSRF、项目隔离和归档项目只读规则。删除均需确认，确认前不发删除请求；清空不受搜索/状态筛选或分页限制。

任务仅允许删除终态（COMPLETED/FAILED/STOPPED/INTERRUPTED）。单条/批量包含非终态时原子拒绝；清空跳过非终态并返回数量。任务级联删除结构化/旧版报告、报告子表、投递/回调/通知和相关幂等记录，保留项目资源。报告可独立删除，保留任务原始数据及其他报告；正在处理报告采用数据库租约防止迟到完成重建。物理产物清理使用持久化重试意图，安全限定任务目录与任务对象路径，不能删除共享脚本/数据集。

接口：DELETE /api/runs/{id}；POST /api/runs/delete {ids:[...]}; POST /api/runs/clear {confirm:true}。报告对应 /api/pressure-reports。响应 {deleted_count,skipped_count,cleanup_pending}，不返回敏感内容；最多100个选择ID。清空需要 confirm=true，不接受跨项目范围。

方案选择：直接在页面删除无法实现真实隔离与关联清理；仅同步清理会因对象存储故障留下不可恢复半完成状态。采用事务删除数据库记录并持久化产物清理意图，物理清理失败重试。此为实现判断，基于本次用户已授权开发、部署和新增功能验收。

验收使用隔离项目、合成终态任务和最小报告夹具，通过页面执行6种删除，覆盖取消、分页、筛选清空、跨项目/活动任务保护、关联清理和重新加载；不提交执行任务、不运行JMeter、不请求业务地址。
