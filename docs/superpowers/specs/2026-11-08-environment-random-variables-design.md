# 环境变量按规则生成与 WS 地址展示

用户要求：WS/Socket.IO 两个地址输入框选择环境后显示具体地址；设备 ID 按规则随机生成，项目和集合环境都可配置；核对长连接参数，部署验证。

沿用 name/value 数组及加密存储，值中保存声明规则，编辑器提供固定值/UUID/随机十六进制/字母数字/纯数字选择和长度。规则严格使用完整值 `{{$random.uuid}}`、`{{$random.hex(32)}}`、`{{$random.alnum(16)}}`、`{{$random.digits(12)}}`，长度 1–256。静态值保持原意；非法规则拒绝保存/执行。不引入脚本、eval 或任意正则生成。

按合并后的有效变量生成：集合覆盖项目。同一次 WS 连接/HTTP 调试操作/执行快照内同名变量只生成一次，重连/重新操作生成新值；登录及心跳复用，持久化始终保存规则。任务快照生成一次且可追溯，不承诺每个压测线程生成不同身份；需要逐线程业务身份仍使用数据集。

WS 字段默认显示环境解析结果，编辑时显示模板，保存模板并随环境切换重新计算；socket_id 为握手动态参数。已有地址预览保留诊断信息。

方案：单次点击生成并保存固定值无法满足每次连接随机；新增结构化 generator 字段会扩展所有兼容接口及迁移；选择现有字符串规则以保持历史与 MCP 兼容。以上属于实现决策，沿用用户已授权范围自主实施。

只测试新增行为，使用本地模拟协议验证设备 ID 一致性与重连变化；不启动业务压测。生产身份不可用时不复制 QA 身份或伪造业务返回参数。
