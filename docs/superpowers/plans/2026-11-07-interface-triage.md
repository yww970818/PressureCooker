# 接口执行详情筛选与下钻

用户要求接口详情增加只看失败、耗时/失败率排序，点击接口直接查看失败原因和日志。沿用当前报告及项目鉴权，不改历史记录，不启动真实业务压测；保留现有协作代码，不整库提交。

契约：GET /api/pressure-reports/:id/steps 支持 failed_only=true|false（空等于false，其他值400）以及 sort=latency|failure_rate|failures。全部查询仍按project/report/node_id/step_key隔离；failed_only仅保留failure_count>0的接口，不删除成功采样或重算指标。筛选及排序必须先于COUNT/LIMIT/OFFSET。latency=P95降序，failure_rate=失败数/总数降序；样本数0的未知失败率排末，真实0%保留，最终position稳定打破平局。可在API返回行补failure_rate百分数或由前端用保存的计数计算；不需要重解析和数据库迁移。

前端由agent独占NodeExecutionDetails.vue及自己的测试。新增“只看失败”复选框、接口排序（耗时P95、失败率、保留失败次数选项）；显示失败率列，说明分母取全部接口采样。只给步骤列表附failed_only，问题/日志使用各自的scope分页且不随列表排序改变。切换筛选/排序重置步骤页，切换报告重置全部状态；目录读取所有全局步骤独立于失败筛选和分页。

点击接口名称保留stable step_key和所选node_id筛选，自动聚焦并滚动到“接口失败原因与日志”面板，明确标题/所选接口/来源范围；旧请求取消且不展示旧接口证据。可返回接口列表，恢复列表筛选/排序，直接查看无关联失败/日志的诚实空态。可以复用现有两个证据区包一层定位面板，避免重复证据实例/请求；不得把整worker日志伪归属步骤。

根会话独占manager/root、集成测试、文档和部署。测试覆盖跨页全量排序、0样本/0%/100%/小数失败率、节点范围、失败仅筛选接口、项目隔离；前端覆盖交互URL、分页复位、点击聚焦/证据联动、快速切换和未知/空日志。构建当前源码，带回滚且仅队列空闲时更新manager；历史实际报告在线桌面/手机验收，保持性能总览/接口独立页签。
