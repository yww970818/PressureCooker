# 独立平台审查与通用化

用户要求独立平台不携带被测项目的定制功能，长连接定制放入项目插件。实施边界见[平台通用能力边界](../../平台通用能力边界.md)。

1. 固定当前源码基线，扫描前端、管理端、执行器、MCP、工具和文档；原始业务资产按 SHA256 外移归档。
2. 移除业务消息、登录、回执、会话和固定变量的核心解释，保留通用传输与显式配置。响应提取默认空，旧未知配置惰性保留。
3. 移除预装业务插件；保留项目内配置/JS插件的创建、导入、安装、解析展示与原文回退；保留原发送路径。
4. 环境只维护通用服务器地址和自定义变量；新安装的 Compose、镜像和证书组织使用平台默认值。既有部署显式保留资源身份。
5. 使用通用 JSON/WS/Socket.IO、本机 JMeter、隔离 MySQL、MCP目录和合成容量夹具定向验收，更新使用指引和文档。
6. 从最终源码冻结并重新构建前端、Go、JMeter扩展及镜像；空闲任务和执行租约下备份、部署、校验服务/产物指纹及新增页面。不得启动真实业务压测。

本次不重写现有密文、历史版本或任务快照；数据只为明确的临时验收对象创建与清理。私有基线、归档回执、测试和发布记录保存在 runtime/acceptance/20261109-generic-platform/。
