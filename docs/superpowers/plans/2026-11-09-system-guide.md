# 系统使用指引 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans，当前会话直接实施。

**Goal:** 在系统主导航提供可搜索的中文使用指引，帮助用户完成环境配置、调试、编排、执行和报告查看。

**Architecture:** 静态内容与 Vue 展示组件分离，沿用现有主题和工作区导航。指引仅发出页面跳转事件，不读取凭据、不创建业务对象、不执行示例；页面选择沿用按项目保存的工作区偏好。

**Tech Stack:** Vue 3、Vitest、现有 CSS 变量；不新增依赖和后端接口。

**Spec:** 本文件按用户“做一个系统使用指引页面”界定页面范围；功能说明以当前 UI、README、报告契约及插件说明为准。

## Global Constraints

- 保留多人未提交修改，以本次涉及文件的 runtime 基线回溯。
- 快速上手、项目环境、接口调试、流程编排、CSV 数据集、任务、报告、集群、插件、MCP、常见问题共 11 个主题。
- 搜索支持中英文、空白和大小写，命中问题正文时显示完整答案；无匹配可清空。
- 预留协议不描述为已能执行，监控缺失不描述为正常；不展示实际密钥和环境值。
- 验证不启动真实业务压测；发布从当前源码重新构建，只更新管理端。

## Review Focus

- 搜索命中 FAQ 正文时答案可见；特殊字符作为文本处理。
- 指引跳转只能使用现有导航 ID，切换不会修改当前项目和环境选择。
- 刷新后可以恢复“使用指引”，未知偏好仍安全回落。
- 归档项目可阅读指引；跳转后的权限仍由原模块控制。
- 窄屏可滚动且不横向溢出，深色主题下正文和示例可读。
