# 大流程首次加载与图表键盘导航补充计划

目标：沿用5000节点规模优化首次加载，补齐趋势图原始点键盘导航；只验证本次变动和直接依赖。不运行百万JTL/万条历史或业务压测，不修改数据库和脚本。

方案：已有profile显示首次流程加载下载3.67MB JavaScript，其中2.75MB来自尚未使用的Scalar/CodeMirror。HTTP/WS编辑弹窗及源码预览改用Vue异步组件；主图详情不等待可独立返回的关联记录。相比新增图数据传输协议或分节点加载，此方案保留完整作者数据、保存/撤销契约，改动面较小。图表绘制继续限制标记数，键盘游标独立在全部原始点中移动。用户已要求直接优化并限定测试范围，延续本会话集成发布授权。
